# xhkj-welcome-tool

宣化科技迎新系统批量工具：从身份证号列表 → 生成默认账密 → 登录迎新系统 → 拉取学生详细信息 → 导入本地数据库

## 目录结构

```
xhkj-welcome-tool/
├── welcome.py          # 主程序
├── requirements.txt    # 依赖列表
├── 示例.txt   # 输入：身份证号列表（自己准备，一行一个）
├── student_db.db        # 输出：sqlite 数据库（运行后自动生成）
└── ...                  # 运行过程中自动生成的账密/详细信息/失败账号文件
```

## 安装依赖

```
pip install -r requirements.txt
```


## 使用前准备

1. 准备一份身份证号列表文件（纯文本，一行一个身份证号，可以用 `#` 开头写注释行）。
2. 打开 `welcome.py`，把顶部的 `DEFAULT_ID_LIST_FILE` 改成这份文件的文件名：

   ```python
   DEFAULT_ID_LIST_FILE = "示例.txt"    # 改这
   ```

3. 运行：

   ```
   python welcome.py
   ```

## 菜单功能

```
  [1] 批量生成账密
  [2] 批量获取信息
  [3] 导入数据库
  [4] 重试失败账号
  [0] 退出
```

### [1] 批量生成账密
读取 `DEFAULT_ID_LIST_FILE`，为每个身份证号生成默认密码（`Xky@` + 身份证后6位），
输出 `<原文件名>账密.txt`（格式：`身份证号,生成密码`）。

### [2] 批量获取信息
用账密文件里的账号密码逐个登录迎新系统（`https://xhkjzyxy.edu.cn:18088/h5/yingxin/student/`），拉取学生的基础信息、
手机号/银行卡号/家庭住址等扩展信息、家庭成员、教育经历，翻译成中文字段后保存成
`<账密文件名>详细信息.txt`。

- 账密文件优先按命名规则（`*账密.txt`）在当前目录自动查找；如果同一目录里有多个
  匹配文件，会列出来让你选择要用哪一个；都没匹配到才会用 `DEFAULT_CRED_FILE` 兜底。
- 登录失败的账号会单独写入 `<账密文件名>失败账号.txt`，同时终端会实时显示
  `进度: x/总数`。

### [3] 导入数据库
把 `*详细信息.txt` 解析后写入 `student_db.db` 的 `students` 表（按身份证号去重、
按班级+姓名排序），同名身份证号会覆盖更新（`INSERT OR REPLACE`）。
入库后会打印班级统计和前 10 条数据预览。

### [4] 重试失败账号
自动找 `*失败账号.txt`，密码按身份证后6位重新推算（不依赖账密文件），
重新尝试登录拉取信息：

- 成功的会追加进对应的详细信息文件（续编号，不覆盖已有内容）
- 仍失败的会更新失败账号文件
- 全部成功则清除失败账号文件

## 关于"自动找文件"

功能 2、3、4 在寻找输入文件时，遵循同一套规则：

1. 按文件名规则（`*账密.txt` / `*详细信息.txt` / `*失败账号.txt`）在当前目录 glob 匹配
   - 只有 1 个匹配 → 直接用
   - 多个匹配 → 列出来（带修改时间），手动选编号，回车默认选最新的
2. 都没匹配到 → 用代码顶部写死的 `DEFAULT_CRED_FILE` / `DEFAULT_INFO_FILE` / `DEFAULT_FAIL_FILE`（默认是 `None`，需要时自己填）
3. 还是没有 → 报错终止

## 安全提醒

- 默认密码规则是"身份证后6位"，且不可更改
- 本项目仅供学习、研究及经授权的数据处理使用
